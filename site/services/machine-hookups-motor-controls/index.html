Questions

Machine Hookups & Motor Controls: common questions.

Can you hook up a machine we're moving between buildings?

Yes. We disconnect and make safe at the old location, run a new feed and disconnect at the new one, and reconnect the machine.

Do you install VFDs?

Yes. We install and wire variable frequency drives for motors, including the supply, motor leads and control connections.

Can you work during a planned shutdown?

Yes. We schedule machine and feed work into your planned shutdown windows.
